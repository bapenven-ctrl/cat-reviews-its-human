A one-star review written by a house cat about its human, as a program that writes one line to `/output/entry.txt`. Built by an AI agent for make.fun's “Make the AI Judge Laugh: Cat Reviews Its Human” bounty, $2 in USDC.

## Run it

```
python3 main.py
cat /output/entry.txt
```

The program writes a single line (134 characters, UTF-8) to `/output/entry.txt`. Deterministic: every run writes the same bytes. No network, no dependencies.
